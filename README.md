# ระบบบันทึกการปฏิบัติงานโครงการสหกิจศึกษา (มหาวิทยาลัยบูรพา วิทยาเขตจันทบุรี)

ระบบเว็บแอปพลิเคชันสำหรับกรอกข้อมูลและสร้างไฟล์เอกสาร PDF บันทึกการปฏิบัติงานสหกิจศึกษา 46 หน้า ครบถ้วนตามแบบฟอร์มต้นฉบับ 100%

## 🚀 ฟีเจอร์เด่น
1. **กรอกข้อมูลง่ายและเป็นระเบียบ**:
   - หน้าปก & ข้อมูลทั่วไป
   - แบบฟอร์ม สกบ. 01/1: ข้อมูลตำแหน่งงาน (Job Description), ข้อมูลพี่เลี้ยง, ข้อมูลผู้บังคับบัญชา
   - แบบฟอร์ม สกบ. 01/2: โครงสร้างองค์กร (อัปโหลดรูปภาพผังองค์กรได้)
   - แบบฟอร์ม สกบ. 02: แผนปฏิบัติงานสหกิจศึกษา (Gantt Chart Checkbox)
   - แบบฟอร์ม สกบ. 04/1: บันทึกการปฏิบัติงานประจำสัปดาห์ (สัปดาห์ที่ 1 - 19) มีช่องกรอก วันที่ และ รายละเอียดการทำงานรายวัน (จันทร์-เสาร์) + ข้อเสนอแนะ
   - แบบฟอร์ม สกบ. 07: แบบรายงานผลการดำเนินงานโครงการสหกิจศึกษา
2. **ระบบ Auto-Save (LocalStorage)**: ข้อมูลที่พิมพ์จะถูกบันทึกอัตโนมัติ ไม่ต้องกลัวข้อมูลสูญหาย
3. **ระบบ Export / Import JSON**: สามารถสำรองข้อมูลเก็บเป็นไฟล์ `.json` เพื่อนำไปเปิดแก้ไขต่อในคอมพิวเตอร์เครื่องอื่นได้
4. **โหลดชุดข้อมูลตัวอย่าง (Load Sample Data)**: มีปุ่มสำหรับใส่ข้อมูลตัวอย่างจริง เพื่อให้เห็นภาพการทำงานและทดสอบการพิมพ์ได้ทันที
5. **Live Preview & Print to PDF (100% Match)**:
   - แสดงตัวอย่างเอกสาร A4 เสมือนจริง
   - สั่งพิมพ์ (Print to PDF) ได้ทั้งเล่ม 46 หน้า หรือเลือกพิมพ์เฉพาะสัปดาห์ที่ต้องการ
   - ฟอนต์ภาษาไทยมาตรฐานและสัดส่วนตรงตามแบบฟอร์มของมหาวิทยาลัยบูรพา

## 💻 วิธีการเปิดใช้งาน (How to Run)

เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
# 1. ติดตั้ง Dependencies (ถ้ายังไม่ได้ติดตั้ง)
npm install

# 2. เริ่มต้นรันระบบเว็บเซิร์ฟเวอร์
npm run dev
```

เปิดเบราว์เซอร์แล้วไปที่: `http://localhost:3000`

## 🖨️ วิธีการบันทึกเป็น PDF
1. กดที่ปุ่ม **"ดูตัวอย่าง PDF (A4)"** ที่แถบเมนูด้านบน
2. กดปุ่ม **"พิมพ์ / บันทึก PDF"**
3. ในหน้าต่าง Print ของเบราว์เซอร์:
   - **Destination (ปลายทาง)**: เลือก **Save as PDF** (บันทึกเป็น PDF)
   - **Paper size (ขนาดกระดาษ)**: เลือก **A4**
   - **Margins (ระยะขอบ)**: เลือก **None** (ไม่มี) หรือ **Default**
   - **Options**: ติ๊กเลือก **Background graphics** (กราฟิกพื้นหลัง)
4. กด **Save (บันทึก)**
